# 📄 Document Q&A System using RAG

An AI-powered document question answering system built using
Retrieval Augmented Generation (RAG) architecture.

---

## 🎯 What it Does

Upload any PDF document and ask questions in natural language.
The AI reads your document and gives accurate answers instantly
without hallucinating or making up information.

---

## ✨ Features

- 📄 Upload any PDF file
- 💬 Ask questions in natural language
- 🔍 Semantic search using vector embeddings
- 🤖 Accurate answers powered by Groq LLaMA 3.1
- ⚡ Fast local vector search using FAISS
- 🖥️ Interactive web UI built with Streamlit
- 💾 Cached embedding model for optimized performance
